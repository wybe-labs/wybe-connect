# wybe-connect

The public, MIT-licensed, dependency-free client side of "Andre KI-assistenter": it lets a
person's coding harness (Claude Code first) feed their Wybe node. The harness only **sends**.
Nothing is read back. Everything is redacted on your machine before it leaves.

Skeleton (C0). The redactor, the transcript reader, the poster and the Claude Code plugin follow
in this repository's history.
